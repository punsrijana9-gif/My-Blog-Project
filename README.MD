# My Personal Blog

## About the Project

My Personal Blog is a simple blog web application built using Node.js, Express.js, and EJS.

This project allows users to create, view, edit, and delete blog posts. It has a clean and simple design with a light pink theme.

## Features

- Create new blog posts.
- View all published posts.
- Edit existing blog posts.
- Delete blog posts with confirmation.
- Responsive design for mobile devices.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS

## How to Run the Project

1. Clone or download this project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the dependencies:

   `npm install`

5. Start the server:

   `node index.js`

6. Open your browser and visit:

   `http://localhost:3000`

## Note

Blog posts are stored temporarily in memory. They will disappear when the server restarts.
